# Wanderlust Travel Website Redesign

A modern, responsive travel website built with **React** for the frontend and **Node.js/Express** for the backend.  
This project showcases travel destinations, travel plans, user testimonials, and booking features with full-stack functionality, automated testing, and DevOps-ready setup.

## Features
- Browse popular travel destinations with images and details
- Explore travel plans and packages
- User testimonials and reviews
- Interactive hero section and floating action buttons
- Fully responsive design (mobile & desktop)
- Contact form integration
- Admin panel for content management (optional)
- Secure authentication with JWT & Bcrypt
- Email notifications via Nodemailer
- Automated testing with **Vitest**
- CI/CD-ready structure for DevOps pipelines

---

## Technologies Used
**Frontend:**
- React, React Router, Tailwind CSS, Bootstrap
- Axios for API calls
- React Testing Library & Vitest for frontend testing

**Backend:**
- Node.js, Express.js
- MongoDB with Mongoose
- JWT authentication
- Nodemailer for email handling
- Bcrypt for password hashing
- Swagger for API documentation

**DevOps & Deployment:**
- Git for version control
- GitHub Actions for CI/CD
- Docker for containerization
- Heroku / AWS for deployment (optional)
- ESLint & Prettier for code quality
- PM2 for process management in production..
